# Udemy Clone Website 🎓

A simple Udemy Clone website built using HTML and CSS.

## Features
- Responsive navigation bar
- Search bar for courses
- Course categories
- Recommended courses section
- Most popular courses section
- Course cards with images, ratings, and prices
- Footer section

## Technologies Used
- HTML5
- CSS3

## Project Overview
This project is a simple online learning platform inspired by Udemy.
It displays course categories, recommended courses, course ratings,
prices, and popular courses in a clean and user-friendly layout.
